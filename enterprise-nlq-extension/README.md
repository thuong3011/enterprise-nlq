# Enterprise NLQ Chrome Extension

Giao diện React + TypeScript chạy trong Chrome Side Panel. Extension gọi backend tại `http://localhost:3000` và hiển thị chat, lịch sử phiên, bảng dữ liệu và biểu đồ.

Xem hướng dẫn tổng quan tại [README.md ở thư mục gốc](../README.md).

## Cài đặt và build

```bash
npm install
npm run build
```

Trong Chrome:

1. Mở `chrome://extensions`
2. Bật `Developer mode`
3. Chọn `Load unpacked`
4. Chọn thư mục `dist`

## Các lệnh

```bash
npm run dev
npm run build
npm run lint
npm run preview
```
